# Naukri Job Market Analytics Dashboard

## Overview
End-to-end Power BI dashboard analyzing 60,645 job postings 
across 8 categories from Naukri.com

## Dashboard Pages
- **Overview** — Total Jobs (485K), Avg Salary (11.14 LPA), High Pay %
- **Roles** — Top companies, job titles, experience vs salary
- **Skills** — Top skills treemap, skills by category
- **Market Insights** — Top cities, avg salary by city, experience levels

## Key Insights
- Bengaluru leads with 142K job postings
- 3-5 years experience is most in demand (53K jobs)
- SQL, Python, Java are top skills
- Accenture is largest recruiter (180K postings)
- Average salary for disclosed jobs: 11.14 LPA

## Tools Used
- Power BI Desktop
- Power Query (ETL)
- DAX Measures
- Python (data cleaning)

## Dataset
- 60,645 job postings
- 8 categories: Data Science, Software Engineering, 
  IT Security, Product Management, and more
- Source: Naukri.com
